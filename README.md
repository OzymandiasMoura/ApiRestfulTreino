Esse projeto foi construido com o objetivo de finalizar o treinamento Back-End do estagio da Fundação Educacional do Municipio de Assis dentro do Centro de Pesquisa em Informatica.

Projeto foi construido com Java SpringBoot, Lombok, H2 database. A IDE utilizada é IntelliJ IDEA 2025.

Seu proposito é unica e exclusivamente educacional. Encontra-se vetada qualquer comercialização.

Todos os direitos reservados.
